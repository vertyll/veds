# Glossary

Every term the documentation uses without defining it on the spot, and where it is explained. The specifications behind
them are in [STANDARDS.md](STANDARDS.md).

| Term                   | Meaning                                                                                                               | Explained in                                                                                                                                                                              |
|------------------------|-----------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Access token           | Short-lived JWT the gateway keeps in its session and exchanges per service.                                           | [Keycloak Configuration: Authentication Flow — Token Handler (BFF) with Authorization Code + PKCE](docs/keycloak.md#authentication-flow--token-handler-bff-with-authorization-code--pkce) |
| Aggregate identifier   | A UUIDv7 the application generates, so the event announcing a row can carry it.                                       | [Architecture: Identifiers](docs/architecture.md#identifiers)                                                                                                                             |
| Attachment             | A file id on a task or comment; dropped when the file is deleted.                                                     | [Files: Keeping references honest](docs/mechanisms/files.md#keeping-references-honest)                                                                                                    |
| Avro contract          | A `*-contracts` module: the Avro schemas of one bounded context and the classes generated from them.                  | [Avro Contracts](contracts/README.md)                                                                                                                                                     |
| BFF (token handler)    | The API gateway signs the user in and holds the tokens; the browser holds only `VEDS_SESSION`.                        | [Keycloak Configuration: Authentication Flow — Token Handler (BFF) with Authorization Code + PKCE](docs/keycloak.md#authentication-flow--token-handler-bff-with-authorization-code--pkce) |
| Board                  | A project's tasks by status, read by one query for the whole page.                                                    | [Board query](task-service/docs/mechanisms/board-query.md)                                                                                                                                |
| Bounded context        | One service's domain: its own model, database, events and language.                                                   | [Architecture: Domain-Driven Design (DDD)](docs/architecture.md#domain-driven-design-ddd)                                                                                                 |
| Command                | A message asking a service to do something; it belongs to the consumer, such as `mail-requested`.                     | [Event Catalog: Commands](docs/events.md#commands)                                                                                                                                        |
| Compensation           | The step that undoes a saga step after a later one failed.                                                            | [Event Catalog: Compensation](docs/events.md#compensation)                                                                                                                                |
| Compensation topic     | `saga-compensation-<service>`, where a service receives what it must undo.                                            | [Sagas: Compensation Topic](docs/mechanisms/sagas.md#compensation-topic)                                                                                                                  |
| CQRS                   | Separate ports for reading and writing; the read side never loads an aggregate.                                       | [CQRS](docs/mechanisms/cqrs.md)                                                                                                                                                           |
| Dead letter topic      | Where a consumed event goes after `MAX_RETRIES` failed attempts.                                                      | [Inbox](docs/mechanisms/inbox.md)                                                                                                                                                         |
| Delivery settings      | Which notification types a user receives, in the app and by e-mail.                                                   | [notification-service: Delivery rules](notification-service/README.md#delivery-rules)                                                                                                     |
| Domain event           | A fact a service publishes about its own data, such as `project-created`; it belongs to the producer.                 | [Event Catalog: Domain events](docs/events.md#domain-events)                                                                                                                              |
| ETag                   | The version of a resource; a write sends it back in `If-Match` and is refused if it is stale.                         | [Optimistic Locking & Concurrency Control: Error Semantics at the API Layer](docs/mechanisms/optimistic-concurrency.md#error-semantics-at-the-api-layer)                                  |
| File scope             | What a file is for (`USER_AVATAR`, `PROJECT_ICON`, `TASK_ATTACHMENT`), with its own size cap and types.               | [File scopes](file-service/docs/mechanisms/file-scopes.md)                                                                                                                                |
| Gateway                | `api-gateway`, the only component the browser talks to; it routes, signs in and exchanges tokens.                     | [Architecture: Overview](docs/architecture.md#overview)                                                                                                                                   |
| Hexagonal architecture | Ports in the application layer, adapters in infrastructure, dependencies pointing inward.                             | [Hexagonal Layering: The rule](docs/hexagonal-layering.md#the-rule)                                                                                                                       |
| Inbox                  | Every consumed event recorded, so a redelivery changes nothing.                                                       | [Inbox](docs/mechanisms/inbox.md)                                                                                                                                                         |
| Invitation             | A project member invited by e-mail, run as a saga until the mail is sent or fails.                                    | [Sagas: Example: Inviting Somebody to a Project](docs/mechanisms/sagas.md#example-inviting-somebody-to-a-project)                                                                         |
| KRaft                  | Kafka's Raft-based mode, which needs no ZooKeeper.                                                                    | [Architecture: Kafka KRaft Mode](docs/architecture.md#kafka-kraft-mode)                                                                                                                   |
| Message key            | A key of the translation catalog sent instead of a sentence; the client renders it.                                   | [Translations: Two tracks: who renders the text](docs/mechanisms/translations.md#two-tracks-who-renders-the-text)                                                                         |
| Notification           | A type and a parameter map stored per recipient; the client renders the sentence.                                     | [notification-service: Messages are keys, not sentences](notification-service/README.md#messages-are-keys-not-sentences)                                                                  |
| Outbox                 | Events written in the same transaction as the change they describe, then published.                                   | [Transactional outbox](docs/mechanisms/transactional-outbox.md)                                                                                                                           |
| Override               | An administrator's text for a key, stored apart from the shipped default so a redeploy keeps it.                      | [Translations: Ownership](docs/mechanisms/translations.md#ownership)                                                                                                                      |
| Permission             | A capability a service checks, declared by that service in its `PermissionCatalogue`.                                 | [Authorization: A permission is declared where it is enforced](docs/authorization.md#a-permission-is-declared-where-it-is-enforced)                                                       |
| PKCE                   | A one-time secret binding the returned code to the browser that started the sign-in.                                  | [Keycloak Configuration: Authentication Flow — Token Handler (BFF) with Authorization Code + PKCE](docs/keycloak.md#authentication-flow--token-handler-bff-with-authorization-code--pkce) |
| Pre-signed URL         | A time-limited storage URL for one object, so the bytes never pass through a service.                                 | [Files: The exchange](docs/mechanisms/files.md#the-exchange)                                                                                                                              |
| Problem document       | The JSON body of every refusal, carrying a message key and its arguments.                                             | [Testing: Why the problem document is pinned twice](docs/testing.md#why-the-problem-document-is-pinned-twice)                                                                             |
| Project role           | A role held inside one project; it never reaches Keycloak.                                                            | [Authorization: Scope](docs/authorization.md#scope)                                                                                                                                       |
| Projection             | A service's local copy of data another service owns, kept current by its events.                                      | [Projections](task-service/docs/mechanisms/projections.md)                                                                                                                                |
| Saga                   | A business process across services, with a compensation for every step that can fail.                                 | [Sagas](docs/mechanisms/sagas.md)                                                                                                                                                         |
| Saga watchdog          | A scheduled job that times out sagas waiting too long for a reply and retries a failed compensation after a cooldown. | [Sagas: Saga Watchdog](docs/mechanisms/sagas.md#saga-watchdog)                                                                                                                            |
| Scope                  | `GLOBAL` or `PROJECT`: where a permission can be held.                                                                | [Authorization: Scope](docs/authorization.md#scope)                                                                                                                                       |
| Single-flight refresh  | One refresh per refresh token, across gateway replicas.                                                               | [Token refresh](api-gateway/docs/mechanisms/token-refresh.md)                                                                                                                             |
| Stock role             | A role a service ships with and its starting permissions; an administrator's edits survive every redeploy.            | [Authorization: Stock roles](docs/authorization.md#stock-roles)                                                                                                                           |
| Token exchange         | The gateway trades the person's token for one whose only audience is the target service.                              | [Token exchange](api-gateway/docs/mechanisms/token-exchange.md)                                                                                                                           |
| `unrestricted`         | The flag that gives `ADMIN` every permission, including ones registered later.                                        | [Authorization: unrestricted](docs/authorization.md#unrestricted)                                                                                                                         |
